Agent 之后的学习

aaaaa Lv4

 2.6k 字  8 分钟  

今天是 2026 年的程序员节 10.24，翻翻记录，发现自己已经近 2 个月没更个人主页了。最近开学后的两个月里，先是忙候选补课，再是忙论文，前不久又是黑客松，整个人忙得不可开交，这周末算是少有的空闲，下周又要开始复习期中考试了。回顾这段时间，发现自己仿佛做了很多事情，但又好像什么也没做——候补选课、论文合作交接、黑客松调试程序这些似乎都是事务性的工作，而真正产出价值的整理笔记、论文写脚本跑实验、黑客松具体代码部分都是交给 Agent 的。这样的时间只能让我感觉到空虚，然而空虚只会带来对做更多事情的渴望，然后更多的事情带来的压力迫使我把它们之中耗费精力的部分交给 Agent，于是我更加感觉空虚——这样的恶性循环或多或少存在于每个工作/兴趣/生活和 Agent 深度结合的人身上。

上周马原老师在课上讲了一个故事，说前不久有个学生和他说，他在学高数的时候学不下去了，就去和 AI 聊天，让 AI 找理由夸他，结果 AI 夸得他心花怒放，让他觉得很满足。当时班里哄堂大笑，不过回寝细想起来，倒是感觉有点照镜子的感觉。

之前我做的各个工具，如 Musician, P@ssw0rd 这些，都是为了自动化某种流程，本质上讲就是图个省事，毕竟天才的灵感都是因为懒惰而产生的嘛。现在，Agent 覆盖了大部分我可以完成的工作，而且完成质量比我高，完成速度也比我快，甚至很多时候效果能够超出我的预期。有这样的工具在，让它辅助我做任何事情都显得荒唐且苍白——凭什么是我指导它工作？任何有想法的人，甚至有的时候包括 Agent 自己，都应该能够指导它工作——我的比较优势在哪里？除此之外，为什么我还需要学习这些 AI 已经充分掌握的知识？用信息论的想法，对于任何一门没有强制闭卷考试或小测要求的科目，Agent 都可以完全取代我，因为它的输入输出效率都远高于我——因此在完全不需要我参与的前提下，我也可以完美地通过这门课，甚至比我亲自学的结果还要来得好。这样的课程存在的意义又是什么？近几年学校课程发生了不少改革，有些课（如《像素着色艺术》）正在消失（因为 AI 已经取代了 Shadetoy 的代码输入，课程的代码部分教学将毫无意义），有些课的 Quiz 正在越来越难，很多课的作业也在越来越难且占分比越来越低——这些改变真的有利于我们学习课节在 AI 时代下有用的内容吗？

以上这些问题，总结起来本质上是 Agent 挤占了“我”的生态位，导致所谓的自我认同开始流失，从而产生了如何自我定位的问题。也就是说，当前如何回答“我是谁”这个问题，决定了接下来“我”是继续空虚下去，还是能和 Agent 以某种形式继续共生，同时找到所谓“心理上的满足感”。这样讲起来看上去像哲学导论的课程论文一样，我不喜欢搞这种理论。我更喜欢解决实际问题的东西。

不妨，我们考虑计算器和口算/笔算的关系：在小学时，我们被教导不要依赖计算器，要有扎实的口算/笔算功底；从结果角度看，应试教育得益于这样的教育方式，擅长口算/笔算的人在升学考试中更有可能有更好的表现，而使用计算器则几乎无益于此；再长远一点看，从高考毕业后，我们几乎极少用到笔算，也只有买东西或打游戏这些我们必须亲自参与的活动中能使用到极少量的口算了。但是，作为学生的我不可能不学习口算/笔算，功利的客观现实会惩罚所有违背考核者意志的人。对这种环境进行建模后，最优解不难求得，我称之为一种两段式的“最优传输”：为了短期未来（即应试要求），应该以最低程度地学习口算/笔算以通过考核；为了长期未来（即生活要求），则应该学会使用计算器而不依赖笔算/口算（我小时候提出这种观点时，长辈总是说我耍小聪明，但是并没有办法有理有据地反驳，现在想想觉得是长辈认为我没有那么长远的计划视角，而只是为了偷懒而提出这种观点，事实上这种批评也不完全错）。现在看来，面临人工智能对工作和学习领域的大面积覆盖和侵入，当年没想清这个问题的人可能需要重新想想了。

类比回 Agent，在长期未来的角度看，Agent 很有可能能够替代大部分现有的人类工作，人的比较优势应该是更好地辅助 AI 进行创造，做一些人类知识凸包之外的创新工作，或者做一些尚在 Agent 能力凸包之外的落地工作，而非想方设法地在人工智能面前螳臂当车，找自我存在感。我在很多课程上听到了这样的观点，我非常认同：从前人类没有交通工具，所以跑步作为生存必要技能之一，是每个人都应当尽可能精通的；如今有了汽车火车，跑步就成为一种健身或竞赛项目了，没有人会去和汽车火车赛跑。同理，Agent 当下，它的编程能力远高于我们，我们程序员也绝不应和 AI 一决高下，而是学会提出准确合理的要求，使用 Agent 更高效地达到目的。

短期未来则是另一个问题。在高考之前的教育，已经“脱离一线”几年的我没有发言权，不过至少我知道，高考还是不允许携带计算器的，更不会允许 AI 辅助。我只谈我周围的本科教育：一部分导师已经想明白了这个问题，只有迫于教务提出的形式性随堂测试，剩下最核心的考核方式是团队 Project——这可以有效锻炼团队合作，对于已经有充分利用 Agent 能力的学生而言，主要考核提出问题和想法的能力。不幸的是，大部分导师还没来得及想明白这个问题，就发现了各种“问题”：学生的作业正确率在一年之内阶跃到近 100%，但考核结果往往并不理想，因此决定为了所谓的“区分度”而增加考核难度、降低作业在成绩中的占比。我在此无意批评这样的客观现实，毕竟我并没有改变这样环境的能力；理性地看，我们只能适应，不是吗？短期来看，我们应该想各种办法来调整我们的学习方式，在满足长期未来的目标（即学会和 Agent 合作共生而有所创造）的同时，以最小的时间精力偏移换取最好的考核结果。对于有闭卷考核的科目，作业可以选择 100% 交给 AI，定期 Agent 辅助地复习也许是效率更高的做法；对于没有闭卷考核的科目，根据具体考核形式可以有更多的选择。当下，由于 Agent 的加入，我们的学习反而又回到了无论形式的原初形式：一切只为掌握知识，“下有对策”的部分则可以交给 Agent 见招拆招。

应试不止个人努力，还有同龄人的对比压力，作为身处应试教育之中的我不得不将其考虑之内，而 Agent 在某种程度上也加大了这种同伴压力带来的焦虑。同样一个任务，如果躬亲完成，可能需要几个小时，但交给 Agent 只需要几分钟，且从结果来看只有人对任务的认知程度略有区别。在这里我不想写小学生文章踩一捧一，客观来讲，更高效的方案就是更好的方案，除非你享受其中。同龄人的压力来自于，如果我选择手工完成，而有些人 Agent 代劳了，那他们势必能够有时间做更多的事情，而我会产生焦虑。这时候，其实不妨这样考虑：比如说，有些人使用 Agent 代做科研发文章，那么他的中稿率如何？如果他的中稿率很高，那么他在学术圈的评价如何？他在面试时能够说出他文章的实现流程和细节吗？如果不能，那他的方法一定不是最优解，我无需焦虑；如果能，那我为什么不使用他的方法呢？显然，这里存在很大的方法优化空间，这需要我们在实际过程中改进；但是从想法上看，这样的思路是理性正确且有利于缓解焦虑的。

这是杂谈系列的第一篇，笔者真的很久没写这么长的话给人看了，句法多少有些生疏，许多地方啰里啰嗦且词不达意，读者懂我意思就好。不久的将来，很有可能这个个人主页也会被 Agent 接管，不过这个系列我还是希望要“坚持手作”，毕竟人的想法还是应该说给人听。
